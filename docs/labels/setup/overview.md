# Overview

The **CompuTec Labels Administrator Guide** explains how to install, configure, and maintain CompuTec Labels.

Use this guide to prepare the CompuTec Labels environment, connect company databases, configure printers and reports, and manage the components required for label and report processing.

## Set up CompuTec Labels

Before users can work with CompuTec Labels, an administrator must install the required components and configure the environment.

The setup includes:

- Checking the [**System Requirements**](/docs/labels/setup/requirements)
- Installing [**CompuTec Labels Printing Manager**](/docs/labels/setup/installation)
- Peforming the [**General Configuration**](/docs/labels/setup/configuration/general-configuration)
- Installing and configuring [**CompuTec Labels for a specific company**](/docs/labels/setup/configuration/company-installation-and-configuration)
- Configuring email accounts when reports need to be sent by email
- Configuring the [**CompuTec Labels SAP Addon**](/docs/labels/setup/computec-labels-sap-addon) when SAP Business One integration is required
- Configuring [**CompuTec Gateway - Printer**](/docs/labels/setup/computec-gateway-printer/configuration) when it is used in the printing environment

## Configuration

Use the [**Configuration**](/docs/labels/setup/configuration/general-configuration) section to configure the components that determine how CompuTec Labels processes and prints labels and reports.

Depending on your environment, configuration can include:

- General settings.
- Companies.
- Printer types and printers.
- Label templates and reports.
- Email accounts.

Complete the configuration required for your printing environment before users start processing label requests.

## Next steps

Start with [**Requirements**](/docs/labels/setup/requirements) to verify that your environment meets the prerequisites for CompuTec Labels.

Then follow the installation and configuration guides to prepare CompuTec Labels for use.

After the system is installed and configured, see the **User Guide** for information about working with label requests, report rules, SQL queries, and other user-facing functions.
