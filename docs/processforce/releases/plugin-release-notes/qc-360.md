# CompuTec Quality Testing Mobile (QC360) Plugin

Below are the release notes for CompuTec Quality Testing Mobile (QC360) Plugin, highlighting new features, improvements, and bug fixes in this release.

## CompuTec QC360 3.2611.1

**Release Date: 6 November 2026**

| Issue Type | Component | Release Note |
| --- | --- | --- |
| Added | QC Analytics | **QC360 now includes a suite of Analytics reports for monitoring quality control activities**, covering batch blocking, test execution, nonconformance resolution, batch history, audits, failure analysis, complaints, inspections, supplier performance, and property results. Reports provide filters, KPI tiles, charts, and drill-downs to help users investigate quality issues. |
| Added | QC Analytics – Batch Blocking | The new **Q1 – Batch Blocking** report shows whether quality control currently blocks a batch or serial number based on QC test statuses and results. |
| Added | QC Analytics – Test Execution | The new **Q3 – Test Execution** report displays QC test statuses and results, with navigation to related batches, serial numbers, and nonconformance reports (NCMRs). |
| Added | QC Analytics – NCMR Resolution | The new **Q4 – NCMR Resolution** report displays nonconformance reports, their resolution statuses, assigned owners, and related QC tests and batches. |
| Added | QC Analytics – Batch History | The new **Q5 – Batch History** report provides a read-only timeline of QC events for a selected batch or serial number. |
| Added | QC Analytics – Audit Snapshot | The new **Q6 – Audit Snapshot** report provides a read-only view of quality control information at a specific point in time to support audits. |
| Added | QC Analytics – Failure Analysis | The new **Q7 – Failure Analysis** report groups historical QC failures by property and reason, helping users identify recurring issues and investigate their causes. |
| Added | QC Analytics – Complaints Register | The new **Q8 – Complaints Register** report lists complaints and provides links to their related QC tests. |
| Added | QC Analytics – Additional Reports | **Four additional reports are now available:** **Q9 – Vehicle Inspection**, with Temperature and Register variants; **Q10 – Supplier Scorecard**; **Q11 – Origin Volumes**, with a By Origin variant; and **Q12 – Property Results**, which displays individual tested properties and supports drill-downs from Q3 and Q7. |
| Added | QC Analytics – Document Creation | **Users can now create related quality control documents directly from Analytics reports.** Available actions include **Create Complaint** from Q3, **Create QC Test** from Q8, and creating a retest for a selected batch from Q1. The created documents are linked to their source records. |
| Added | QC Analytics – Batch Management | **The new Lock Impacted Batches action in Q2 allows users to lock multiple affected batches at once.** The action requests confirmation and displays the result for each batch, including any failures. |
| Added | QC Analytics – Assignments | Users can now assign complaint owners and QC test inspectors directly from Analytics reports using the **Assign Owner** and **Assign Inspector** actions. |
| Added | QC Analytics – Status Management | **Users can now manage QC document statuses directly from Analytics reports.** Available actions include **Start**, **Hold**, **Resume**, and **Close** for complaints and NCMRs, subject to the applicable ProcessForce status rules. QC test status actions also support the appropriate transitions. |
| Added | QC Analytics – Batch Traceability | The **Open BT360** action allows users to open batch traceability for the selected batch directly from QC Analytics reports. |
| Added | QC Analytics – Manufacturing Orders | Supervisors can now use **Escalate**, **Release**, **Reschedule**, and **Freeze/Unfreeze** actions for Manufacturing Orders from supported Analytics reports. The **Escalate** action can increase an order's priority and append a supervisor note without overwriting existing remarks. |
| Added | QC Analytics – Printing | **Users can now print QC tests, NCMRs, and complaints directly from Q3, Q4, and Q8.** The available layouts are taken from the corresponding SAP Business One document type, with its default layout preselected. |
| Improved | QC Analytics – Navigation | Reports now provide additional drill-downs between related quality control information, including navigation from Q3 to NCMRs in Q4, failure analysis in Q7, and property results in Q12. |
| Improved | QC Analytics – Refresh | **Reports Q1–Q8 now support manual refresh**, allowing users to reload the latest data without losing their current filters. The refresh option is also available again in Q12. |
| Improved | QC Analytics – Report Layouts | Reports now display key information more clearly. Q1 and Q2 show their most important columns first, Q3, Q4, and Q8 include document numbers and numbering series, and unnecessary empty columns are hidden by default. |
| Improved | QC Analytics – KPI Descriptions | KPI tiles and chart tabs now include descriptions explaining what their values represent. Percentage columns also display the percentage sign (%). |
| Improved | QC Analytics – Printing | Printing from Q3, Q4, and Q8 now uses the layouts configured for the current company database instead of fixed layout codes. |
| Fixed | QC Analytics – Report Data | **Cancelled QC tests, NCMRs, and complaints no longer appear in QC Analytics reports.** Reports also retain relevant information when related records are missing or cancelled, including QC tests without an available test protocol and NCMRs linked to cancelled tests. |
| Fixed | Q3 – Test Execution | **QC tests covering multiple batches no longer appear as duplicate rows.** Tests without batch lines are also displayed correctly. |
| Fixed | Q1 – Batch Blocking | Batches are now identified correctly even when revision codes differ, allowing **Lock Batch** and **Release Batch** actions to work for the affected records. The status filter also includes the **N/A** batch status. |
| Fixed | QC Analytics – SAP Business One Integration | **QC360 context menus now work correctly on SAP HANA** and no longer prevent other plugins' menu entries from appearing. Opening a report from a SAP Business One document also applies the selected document as a filter instead of displaying all records. |
| Fixed | QC Analytics – Batch Management | The **Lock Impacted Batches** action in Q2 now locks the affected batches rather than the source batch. |
| Fixed | QC Analytics – Document Creation | Creating QC tests from complaints or batches now validates that the selected test protocol belongs to the corresponding item. If a newly created document cannot be linked to its source, it is removed to prevent unlinked records. |
| Fixed | QC Analytics – Status Management | **Changing the status of a QC test, complaint, or NCMR from an Analytics report now applies the correct status and status date.** This prevents incorrect transitions and validation errors in ProcessForce. |
| Fixed | QC Analytics – Actions | Failed document creation and batch-locking actions now display meaningful error messages instead of `Error: 0`. QC test status-change messages also display the status name in the user's language. |
| Fixed | QC Analytics – Drill-Downs | Drill-downs in Q1 and Q3 no longer open unrelated records when the selected row has no batch or serial number. |
| Fixed | QC Analytics – Configuration | Editing standard QC360 reports in **Analytics Creator** no longer removes their configured actions. Report actions, filters, links, and print settings are also retained when the plugin is redeployed. |
| Fixed | QC Analytics – Data Display | Reports no longer display an incorrect pool value of `0` for QC tests that are not assigned to a QC pool. The misleading **Impact Count** total has also been removed from Q2. |
| Fixed | QC360 Mobile App | **Several QC360 mobile app issues have been resolved**, including problems with favorites, attachment uploads, duplicate reference-list entries during property recording, confirmation after adding multiple results, defect updates, test status editing, and form layouts on mobile devices. Property recording also works correctly when no reference-code filter is specified. |

## CompuTec QC360 3.2606.1

**Release Date: 18 June 2026**

| Issue Type | Component | Release Note |
| --- | --- | --- |
| New | QC360 | Added support for saving and reusing personal filter sets in **QC360**, making it easier to quickly access frequently used **Quality Control** views. |
| Improved | QC360 | Improved search and filtering behavior for more consistent and reliable results. |
| Improved | QC360 | Added ``Completed`` and ``Reopened`` statuses to **QC Test Pool** to support more accurate status management and improve compatibility with integrations and custom extensions. |

:::warning[important]

**CompuTec QC360 3.2606.1** requires:

    - **CompuTec ProcessForce 3.2606.3** or higher
    - **CompuTec Core 3.0.1.577** or higher

:::
