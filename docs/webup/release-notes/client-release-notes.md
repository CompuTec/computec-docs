# CompuTec WebUp Client Release Notes

## CompuTec WebUp Client 1.2610.2

**Release Date: 21 October 2026**

| Issue Type | Component | Release Note |
| --- | --- | --- |
| Added | Browser Extension | **CompuTec WebUp Client** is now available in the **Firefox Browser Add-ons store**, making it easier for Firefox users to find and install the extension. |
| Added | Smart Actions | You can now choose whether **Navigation Smart Actions** open in the current window or a new browser tab, giving you more control over navigation. The current window remains the default option. |
| Improved | Data Binding | **CompuTec WebUp Client** can now detect changes to values in the **SAP Business One Web Client** model, including changes caused by automatic recalculations rather than direct user input. Extensions that enable this functionality can receive information about changed values and update their controls accordingly. |
| Fixed | Firefox Compatibility | **CompuTec WebUp Client** now loads correctly in **Mozilla Firefox**, allowing you to use the extension without encountering the `chrome is not defined` error. |
