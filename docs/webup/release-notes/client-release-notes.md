# CompuTec WebUp Client Release Notes

## CompuTec WebUp Client 1.2610.2

**Release Date: 24 October 2026**

| Issue Type | Component | Release Note |
| --- | --- | --- |
| Added | Smart Actions | You can now choose whether **Navigation Smart Actions** open in the current window or a new browser tab, giving you more control over navigation. The current window remains the default option. |
| Improved | Data Binding | **CompuTec WebUp controls** now update automatically when values change in the **SAP Business One Web Client**, whether you edit a field directly or its value is recalculated. For example, a control bound to **Document Total** now reflects changes made to document lines without requiring you to edit the total manually. |
| Fixed | Firefox Compatibility | **CompuTec WebUp Client** now loads correctly in **Mozilla Firefox**, allowing you to use the extension without encountering the `chrome is not defined` error. |
